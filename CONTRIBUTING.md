# Contributing

Thank you for contributing to this NPM package.

Steps:

- Fork the repository and create a branch per change: `git checkout -b feature/your-change` (Git Flow: `feature/`, `bugfix/`, `chore/`, `hotfix/`, `release/`)
- Install: `npm install`
- Run tests: `npm test`
- Commit with Conventional Commits and open a Pull Request against `develop` (the PR title must be a Conventional Commit, e.g. `feat: add x`).

Code style:

- Keep CLI behavior backwards compatible where practical.
- Add tests for significant logic changes.
